# RansForLearn

An educational ransomware project for **ethical hacking** (my first project!).  
This ransomware encrypts `.txt` files using **AES encryption**.

I developed this project in Python to better understand how black hat hackers operate —  
so I can think like them, detect their techniques, and build better defenses.
